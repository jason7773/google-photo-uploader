📸 專案目的

此工具專為 Google Pixel 1 (OG) 設計，用於將 Google Photos Takeout 匯出的照片/影片，修復遺失的 GPS 座標與拍攝時間後，自動推送到手機，以享受「原始畫質免費無限空間」福利。

🔒 資料安全
所有運算皆在您的電腦本機執行（Local），不會將照片上傳至任何第三方伺服器。

🔧 前置準備 (必讀)

本工具依賴由您自行下載的外部工具，請確保以下檔案已放入 gp-p1-mig/tools/ 資料夾中：

1. ADB (Android Debug Bridge)

用於推送檔案到手機。

  1. 下載 SDK Platform-Tools (Windows)
  2. 解壓縮，將 adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll 放入 tools/ 資料夾

2. ExifTool

用於寫入照片 Metadata。

  1. 下載 Windows Executable
  2. 解壓後將 exiftool(-k).exe 重新命名為 exiftool.exe
  3. 放入 tools/ 資料夾

3. FFmpeg

用於修復影片 Metadata。

  1. 下載 ffmpeg-git-essentials.7z
  2. 解壓取出 bin/ffmpeg.exe，放入 tools/ 資料夾
✅ 檢查方式
看儀表板上方的「工具狀態」燈號。若顯示紅色 ✗ 代表找不到檔案，請檢查檔名與路徑。

💡 重要技巧

  • 分批處理：Google Takeout 檔案通常很大，建議一次處理一個 ZIP，但 Reconcile 建議在所有 ZIP 匯入後再執行，或是每匯入一個就執行一次也可以（未匹配的會保持 NEW 狀態）。
  • Retry Failed：若 Patch 過程中有失敗（例如 Exif 損壞），請點擊「Retry Failed」。程式會嘗試用更強力的修復模式（-fast2）並進行資料驗證，通常能解決 99% 的問題。
  • Push 路徑：預設推送到 /sdcard/DCIM/Camera，這樣 Google Photos App 開啟後就會自動偵測並備份。

❓ 常見問題

Q: Push 時找不到手機 (no devices/emulators found)？

這是最常見的問題。請檢查：
1. 手機是否已開啟「開發人員選項 > USB 偵錯」？
2. 插上 USB 線時，手機螢幕是否有跳出「允許 USB 偵錯嗎？」的詢問視窗？請務必點選「允許」。
3. 下拉通知列，確認 USB 連線模式是否為「檔案傳輸 (File Transfer)」或 PTP，不要選「僅充電」。

Q: Push 時出現 [WinError 2] 系統找不到指定檔案？

這代表系統找不到 adb.exe。請確認您已將 adb.exe 放入 gp-p1-mig/tools/ 資料夾中，或者已安裝在系統 PATH 路徑下。修正後請重新整理網頁。

Q: Push 的路徑要填什麼？

請填寫 Android 的路徑，例如 /sdcard/DCIM/Camera。
❌ 不要填寫 Windows 路徑（如 C:\Users\... 或 本機\Pixel...），ADB 看不懂 Windows 路徑。

Q: 為什麼有些照片狀態是 NEW 但一直無法 Patch？

這些照片可能缺少對應的 JSON sidecar 檔案（metadata）。這通常發生在分批下載 Takeout 時，JSON 檔在另一個 ZIP 裡。請繼續匯入其他 ZIP 檔，再次執行 Reconcile 即可。

🛠️ 進階疑難排解

ADB 連線自我檢測

# 在終端機執行
cd gp-p1-mig/tools
./adb devices

應顯示如下內容：

List of devices attached
FA6B90303015    device

若顯示 unauthorized，請檢查手機螢幕並按「允許」。
若列表為空，請檢查 USB 線或驅動程式。

ExifTool 修復失敗

若遇到 OtherImageStart 等錯誤，請直接按 Web UI 上的 Retry Failed。新版程式已內建自動驗證邏輯，即使 ExifTool 回報錯誤代碼，只要資料正確寫入就會判定為成功。
