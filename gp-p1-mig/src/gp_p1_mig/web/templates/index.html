📸 專案目的

此工具將 Google Photos Takeout 匯出的照片/影片，修復 GPS 座標與拍攝時間後，透過 Pixel 1 手機重新上傳回 Google Photos，以保留「原始畫質免費無限空間」的福利。

🔒 完全本地端運行
所有資料處理均在你的電腦上完成，不會上傳至任何伺服器。此瀏覽器介面僅是本機程式的圖形操作介面。

🔧 前置準備

1. ExifTool（必須）

  1. 前往 exiftool.org
  2. 下載 Windows Executable
  3. 將 exiftool(-k).exe 改名為 exiftool.exe
  4. 放入 gp-p1-mig/tools/exiftool.exe

2. FFmpeg（影片處理必須）

  1. 前往 gyan.dev/ffmpeg
  2. 下載 release essentials
  3. 解壓後將 ffmpeg.exe 放入 gp-p1-mig/tools/ffmpeg.exe

3. 安裝 Python 套件

pip install -e .

💡 多個 ZIP？
分別執行 Ingest，程式會自動去重。Reconcile 只需執行一次即可比對全部。

❓ 常見問題

如何看更詳細的日誌？

在 CLI 模式加 --verbose 旗標，例如 gp-p1-mig patch --verbose。Web UI 的日誌面板則會即時顯示所有 INFO 及以上日誌。

Patch 失敗了怎麼辦？

點選儀表板的 Retry Failed 按鈕，會自動重置 FAILED 項目並重新嘗試。

(0,0) 座標是什麼意思？

Google Takeout 用 (0, 0) 表示「無地點資訊」。本程式會自動過濾，不寫入 GPS。

如何確認 GPS 方向正確？

Patch 程式會自動讀回 metadata 做比對驗證（容許 ±0.001°），若有錯誤會標記為 FAILED。你也可以手動用 exiftool -GPSLatitude -GPSLatitudeRef file.jpg 檢查。

🔧 問題排除

ExifTool 找不到

確認 exiftool.exe 位於 gp-p1-mig/tools/ 目錄內，且已改名（去除 (-k) 後綴）。儀表板頂部工具偵測器會顯示目前偵測狀態。

ADB 推送失敗

1. 確認手機已連接電腦
2. 確認已開啟 USB 偵錯
3. 手機上點選「允許 USB 偵錯」
4. 執行 adb devices 確認裝置有列出

DB 被鎖

若顯示 "database is locked"，請確認沒有其他程式（如 DB Browser）正在開啟同一個 state.db。

卡在初始化 / 按鈕沒反應

查看日誌面板是否有 ERROR。大多數情況是路徑設定不正確，請到「系統設定」確認 Root 與 DB 路徑。
